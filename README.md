An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every official name, description and grade, a guide in its own words with cited sources for each trophy, a five-stage roadmap to the platinum, the one potentially missable trophy flagged, and a checklist that saves in the browser with export and import, filters by kind, and a spoiler-safe mode that hides story trophies until they are earned. No network requests at run time — serve `app/` from any static server and it works with the network off.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
